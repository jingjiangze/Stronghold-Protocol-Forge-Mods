怎么装

unzip Stronghold-Protocol-Forge-modmgr-0.3.1-lite.zip
cd Stronghold-Protocol
npm start            # http://localhost:3000
                     # 管理器页面：http://localhost:3000/mod
  • 需要 Node.js 22 或 24。
  • 游戏素材不在包里：首次启动 npm run setup 会按 data/assets.json 缺什么下什么，可断点续传。
  • 素材默认走 speedcdn（也可用官方 CDN 整合包，把素材地址指到 CDN）。
  • 管理器 /mod 只在本机 / 局域网可访问；写入需要 plugins/.studio-key 这把业主钥匙。
